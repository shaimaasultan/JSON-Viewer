# 📊 JSON Table Viewer

A lightweight, browser-based tool for parsing and visualizing JSON log files in tabular format. Designed for forensic clarity, modular filtering, and emoji-enhanced log inspection.

---

## 🔍 Features

- ✅ Auto-parsing of JSON logs with fields:
  - `timestamp`, `level`, `emoji`, `logger`, `message`, `filename`, `line`, `function`
- 🔄 Switchable views: Table View and Pivot View
- 🧹 Filter controls: Apply filters by key/value pairs
- 🧩 Column toggles: Show/hide specific fields for focused inspection
- 📁 File metadata: Displays filename, line number, and function origin
